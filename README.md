# TimeMint

| Folder      | Stack |
|-------------|-------|
| `frontend/` | Nuxt 3 (JavaScript), Tailwind CSS, axios, Pinia, VueUse |
| `backend/`  | Node.js, Express 5, SQLite (better-sqlite3) |

## Run locally

```bash
# terminal 1
cd backend && cp .env.example .env && npm install && npm run dev    # :4000

# terminal 2
cd frontend && cp .env.example .env && npm install && npm run dev   # :3000
```
